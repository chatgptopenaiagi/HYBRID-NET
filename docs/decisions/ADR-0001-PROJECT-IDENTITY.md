# ADR-0001: Project identity and scope

Status: **ACCEPTED**. Date: 2026-10-22. Classification: **ENGINEERING DECISION**.

## Context

The founding mission describes a framework connecting human intent, agents,
application engines, language runtimes and computers. Calling it a universal
desktop-control tool would obscure its emphasis on direct machine interfaces.
Calling the documentation a runtime would overstate Genesis 1.

## Decision

The project is **HYBRID.NET**, expanded as Hybrid Native Execution and
Interoperability Framework; its repository is **HYBRID-NET**. AIXR names the
conceptual Artificial Intelligence Execution Runtime subsystem. Version 0.0.1 is
an architecture foundation. Microsoft .NET is a candidate dependency and language
ecosystem, not the project's owner or identity.

Genesis 1 preserves architecture, boundaries, decisions and measurable future
milestones. No application executable, installer or adapter is claimed. The dual
executable idea is preserved as a founding concept without asserting legal novelty,
patentability or exclusive invention of related techniques.

## Consequences and alternatives

Future components share this identity and evidence vocabulary. A renamed runtime,
merged neighboring repository or premature universal-automation implementation
would lose the intended scope. Separate repositories remain independent.

## Validation

Documentation review must find the identity and current implementation boundary in
README, status and agent continuity instructions. Later milestone reports must
identify concrete implemented components and verified behaviors separately.
