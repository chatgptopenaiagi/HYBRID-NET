# Examples and future demonstrations

Status: **conceptual examples; no runnable product demo**.

The current [HMCP examples](../protocols/README.md) illustrate capability metadata,
invocation identity and an unknown execution outcome. Names, paths and identifiers
are synthetic. They are not credentials, verified capabilities or live endpoints.

The preferred first runnable example is the
[Genesis 2 LibreOffice DOCX-to-PDF experiment](../docs/genesis/GENESIS-2-EXPERIMENT.md).
It will use a controlled fixture, ten predetermined criteria, independent PDF
verification and local SQLite evidence, without a central server or GUI automation.
A synthetic process exchange may prepare its contracts but cannot replace the proof.
POK may eventually demonstrate machine-readable game state and deterministic controls.
These are future milestones, not capabilities implied by the conceptual JSON examples.
See [candidate adapters](../adapters/REFERENCE-TARGETS.md).
