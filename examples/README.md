# Examples and future demonstrations

Status: **conceptual examples; no runnable product demo**.

The current [HMCP examples](../protocols/README.md) illustrate capability metadata,
invocation identity and an unknown execution outcome. Names, paths and identifiers
are synthetic. They are not credentials, verified capabilities or live endpoints.

The first future runnable example should use two local processes and a bounded
synthetic operation with fixtures fixed before code. It should need no application
installation, AI provider, internet or central server. A later LibreOffice example
may create a document and export a PDF through supported automation, with independent
artifact checks. POK may eventually demonstrate machine-readable game state and
deterministic controls. These are separate milestones, not implied by JSON examples.
See [Genesis 2 plan](../ROADMAP.md) and [candidate adapters](../adapters/REFERENCE-TARGETS.md).
